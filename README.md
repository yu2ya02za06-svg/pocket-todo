# ポケットToDo（PWA版）

期限日つきのやることリストです。スマホのホーム画面に追加でき、電波がなくても使えます。
データはそのスマホのブラウザ内に保存されます（PCとの同期はありません）。

## ファイル
- `index.html` アプリ本体
- `manifest.webmanifest` アプリ名・アイコンなどの情報
- `sw.js` オフラインで開くための仕組み（Service Worker）
- `icon-192.png` / `icon-512.png` / `maskable-512.png` / `apple-touch-icon.png` アイコン

## スマホへのインストール（Android / Chrome）
1. GitHub PagesのURLをChromeで開く
2. 画面の「ホーム画面に追加」か、Chromeのメニュー（︙）→「ホーム画面に追加」→「インストール」
3. ホーム画面のアイコンから起動すると、アプリとして全画面で開きます

一度開いておけば、以降は機内モードでも起動できます。

## 注意
- Chromeの「サイトデータを削除」を行うと、リストも消えます。
- アプリを更新したら `sw.js` の `CACHE` の名前（pocket-todo-v2）の数字を上げると、スマホ側にも確実に反映されます。
